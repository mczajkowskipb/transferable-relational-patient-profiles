# Preliminary figures

All figures are SVG and can be regenerated from the committed CSV results with:

```bash
python -m pip install matplotlib
python scripts/generate_preliminary_figures.py
```

- `structural_retention_overview.svg` — authentic structural endpoint.
- `signature_damage_pass_fraction.svg` — Module C.
- `core_dropout_assigned_fraction.svg` — Module D.
- `geometry_perturbation_ari.svg` — Module B.

The figures are explanatory summaries. The authoritative numerical results remain the committed CSV/JSON files.
