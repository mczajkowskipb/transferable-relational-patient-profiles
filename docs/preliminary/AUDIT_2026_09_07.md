## B. Reuse from historical pilot

Reuse the conceptual contracts of integrity-checked matrices, fixed reference commits/checksums, label-free bundles, frozen source preprocessing, target assignment and source/label namespace tests. Port only small necessary pieces with attribution and tests.

Do not directly reuse the historical v2 runner as the new benchmark:
1. `scripts/20_run_pilot_v2.py::relation_matrix` forms relations on robust feature-standardised Z. `run_real_prelabel` then executes post-hoc rules on raw `b.X`. Thus its post-hoc comparison has a training/execution scale mismatch.
2. `top_features` computes MAD after dividing each feature by its MAD. For nondegenerate features this largely normalises the screening statistic to one; ordering can then depend on rounding/tie-breaking. This differs from RR_DIRECT's raw source MAD screen.
3. VALUE/PAM uses a different feature budget. Historical differences do not isolate the induction algorithm.
4. v2's NULL proxy combines ARI against synthetic labels and margin. It does not show a source-only detector of absent structure.
5. Historical favorable transfer ARIs are assigned-sample ARIs, with coverage reported separately.
6. Matrix adapters do not establish the needed participant-pair map or biological gene mapping by themselves.

These findings do not rewrite historical CSVs, STOP decisions, or freeze documents. Pilot v2 remains STOP (4/5), and v2.1 remains an identifiability diagnostic.

## D. Confirmed current-code defects and repairs

- RR_DIRECT emits direction 0/1. `artifact_from_rr_direct` passed 0 directly into `RPPRelation`, which rejects anything other than -1/+1. Reproduced on a four-row synthetic source. Converter now maps 0 to -1, retains valid signed inputs and rejects invalid codes.
- RR_DIRECT scored reverse rules as NOT(a>b), counting ties as success; the artifact used strict a<b. Induction support also used the complement. Current code now treats ties as satisfying neither orientation in support calculation and scoring. Non-tie direction support is unchanged.
- Existing tests all passed before these repairs but did not cover the integration boundary. Ten added tests cover conversion, strict ties, induction tie support, consistent execution, invariance, cohort independence, dropout and serialization.
- `python scripts/verify_preliminary_preflight.py` executes the nine existing fixture-free test functions plus ten unittest regressions. **19 passed**. Pytest itself was unavailable locally; the normal CI workflow still uses pytest.
- These are current-code pre-pilot corrections, not repairs to historical evidence. Any future V1 must record this implementation version.
